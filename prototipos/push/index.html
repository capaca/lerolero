Lero-lero · receber notificação

Este aparelho faz o papel de quem recebe a mensagem. Mede se o aviso chega com o app fechado, enviado direto pelo navegador de quem manda, sem servidor do projeto (Q-M2). Instale esta página (menu do navegador → Instalar app) e faça os passos no app instalado.

Aparelho

1 · Ativar as notificações

Gera um par de chaves VAPID só deste aparelho e pede ao navegador um endereço de push.

2 · Mandar o convite para quem vai enviar

No app, isto iria no cartão de perfil, só para os contatos. Mande o link para o computador (ou outro celular) e abra lá. Depois de trocar as chaves, o link antigo deve parar de funcionar.

3 · Testar daqui, com a página aberta

Manda um aviso para este mesmo aparelho. Responde se este navegador consegue fazer o POST.

Avisos recebidos

Anotados pelo service worker quando o aviso chega. "Janelas" diz se havia o app aberto naquela hora; o atraso usa o relógio dos dois aparelhos.
